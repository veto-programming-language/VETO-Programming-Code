# Veto (`vetoc`) v0.3 — Bare-Metal Systems Language

> **Строже, чем Rust. Без сборщика мусора. Без проверок в рантайме.**  
> Компилируемый язык программирования с паспортными диапазонами типов (`i32<min..max>`, `u8<0..255>`), математической верификацией границ массивов и памяти на этапе компиляции и встроенным **ИИ-Инквизитором (`prove(...)`)**.

---

## Почему на Veto сложнее и интереснее писать ОС, чем на Rust

1. **Никакого `unsafe` как лазейки:** даже при обращении к видеопамяти `0xB8000` или массивам ядра компилятор требует математического доказательства, что индекс не выйдет за пределы буфера (`0..1999`).
2. **Контракты на каждый байт:** все аргументы функций, переменные и возвращаемые значения обязаны иметь строгие интервалы `<min..max>`.
3. **Суд Инквизитора (`--features inquisitor`):** при встрече `prove(...)` или спорной арифметики компилятор требует строгое математическое обоснование, а в режиме `VETOC_ALLOW_MANUAL=1` устраивает допрос программисту.

---

## Сборка ядра ОС и запуск в QEMU

### Зависимости (Linux / Ubuntu / Debian)
```bash
sudo apt update && sudo apt install -y build-essential gcc-multilib qemu-system-x86 cargo rustc
```

### Компиляция загрузочного ядра (Multiboot x86)
```bash
cargo run --features inquisitor -- kernel.vt --kernel
qemu-system-i386 -kernel veto_kernel.elf
```

## Системный API ядра (`--kernel` Bare-Metal Runtime)

### 1. Прерывания процессора (IDT, PIC 8259A, PIT)
* `idt_init()` — инициализирует таблицу дескрипторов прерываний (IDT), перенастраивает PIC (`IRQ0..15 -> INT 32..47`), запускает системный таймер PIT на 100 Гц и включает прерывания (`sti`).
* `irq_ticks() -> i32<0..2147483647>` — возвращает количество аппаратных тиков таймера (100 тиков = 1 секунда).
* `irq_pop_key() -> u8<0..255>` — извлекает скан-код клавиши из кольцевого буфера прерывания клавиатуры `IRQ1` (`0`, если буфер пуст).

### 2. Видеопамять VGA (`0xB8000`, 80x25)
* `vga_poke(idx: i32<0..1999>, ch: u8<0..255>, color: u8<0..255>)` — запись символа и атрибута цвета в ячейку экрана (выход за `1999` блокируется компилятором).
* `vga_print(row: i32<0..24>, col: i32<0..79>, str: "текст", color: u8<0..255>)` — вывод строки на экран.
* `vga_set_cursor(row: i32<0..24>, col: i32<0..79>)` — перемещение аппаратного курсора VGA.

### 3. Порты ввода-вывода, физическая память и CPU
* `port_in8(port: u16<0..65535>) -> u8<0..255>` / `port_out8(port: u16<0..65535>, val: u8<0..255>)` — прямая работа с портами x86 (`inb` / `outb`).
* `mem_read8(addr)` / `mem_write8(addr, val: u8<0..255>)` — чтение и запись байта по физическому адресу.
* `mem_read32(addr)` / `mem_write32(addr, val)` — чтение и запись 32-битного слова по физическому адресу.
* `cpu_cli()` / `cpu_sti()` — запрет и разрешение прерываний.
* `cpu_halt()` — остановка ядра (`hlt`) до следующего аппаратного прерывания.
* `cpu_reboot()` — аппаратная перезагрузка через контроллер `0x64`.

## Челлендж для разработчика ОС

Используя этот API и строгую систему диапазонов Veto, реализуйте с нуля:
1. Таблицу перекодировки скан-кодов PS/2 в ASCII-символы (массив `[u8<0..127>; 128]`).
2. Командный интерпретатор (шелл) с поддержкой `Backspace`, `Enter`, скроллинга экрана и команд `help`, `uptime` (через `irq_ticks()`), `clear`, `reboot`.
3. Простой аллокатор физических страниц памяти поверх `mem_read32` / `mem_write32`.

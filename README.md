# VETO (v0.4.2)

veto is experimental mess with very strict compiler

IT IS IN VERY EARLY ALPHA

## Quick Start & CLI

```bash
git clone https://github.com/veto-programming-language/VETO-Programming-Code
cd VETO-Programming-Code
cargo install --path .
```

```bash
vetoc kernel.vt --kernel -o kernel.elf
vetoc suite.vt --test
```
